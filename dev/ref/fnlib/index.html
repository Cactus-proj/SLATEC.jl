SLATEC.FNLIB — Module
SLATEC.FNLIB

A collection of routines for evaluating elementary and special functions.

Most of the these routines were written by Wayne Fullerton while at LANL. Some were written by Don Amos of SNLA. There are approximately 63 single precision, 63 double precision and 25 complex user callable elementary and special function routines.

Categories

Intrinsic Functions and Fundamental Functions

  • Unpack/Pack floating point: r9upak, r9pak
  • Initialize/Evaluate orthogonal polynomial: inits, csevl

Elementary Functions

  • Elementary Functions: carg, cbrt, clog10
  • Relative error exponential: exprel
  • Relative error logarithm: alnrel, r9ln2r

Trigonometric and Hyperbolic Functions

  • Tangent, cotangent: ctan; cot
  • Trig in degrees: sindg, cosdg
  • Arc Trig: casin, cacos, catan, catan2
  • Hyperbolic: csinh, ccosh, ctanh
  • Arc hyperbolic asinh, acosh, atanh; r9atn1

Exponential Integrals and Related Functions

  • Exponential integral: ei, e1; exint
  • Logarithmic integral: ali

Gamma Functions and Related Functions

  • Factorial and Binomial: fac, binom
  • Gamma: gamma, gamlim, gamr
  • Log gamma: alngam, algams; r9lgmc; c0lgmc
  • Incomplete gamma: gami, gamic, gamit
  • Digamma and Poch: psi, psifn, poch, poch1
  • Beta: beta, albeta, betai

Error Functions and Fresnel Integrals

  • Error function: erf, erfc
  • Dawson's function: daws

Bessel Functions

  • Bessel functions: besj0, besj1, besy0, besy1
  • Modified (hyperbolic) Bessel functions: besi0, besi1, besk0, besk1
  • Modified (hyperbolic) Bessel functions, scaled by an exponential: besi0e, besi1e, besk0e, besk1e
  • Sequences of Bessel functions: besj, besy, besi, besk; besks, beskes

Bessel Functions of Fractional Order

  • Airy functions: ai, bi
  • Exponentially scaled Airy functions: aie, bie

Confluent Hypergeometric Functions

  • Confluent Hypergeometric: chu

Miscellaneous Functions

  • Spence dilogarithm: spenc

SLATEC.FNLIB.exint — Function
exint(x::Float32, n::Int32, kode::Int32, m::Int32, tol::Float32)
exint(x::Float64, n::Int32, kode::Int32, m::Int32, tol::Float64)

Compute an m member sequence of Exponential integral: $E_{n+k}(x), k = 0,1,...,(m-1)$ for n >= 1 and x >= 0.

Formula: the integral from 1 to infinity of $(e^{-x*t}/t^{n+k}) dt$

  • x: x > 0 for n=1 and x >= 0 for n >=2
  • n: Order, n >= 1
  • kode: Selection parameter (1=normal, 2=scaled)
  • m: Number of terms to compute, m >= 1
  • tol: Relative accuracy wanted, ETOL=R1MACH(4) < tol < 0.1

Return (en, nz, ierr)

  • en: Result array
  • nz: Underflow indicator
  • ierr: Error flag

Fortran Name: EXINT(X,N,KODE,M,TOL, EN,NZ,IERR), DEXINT(X,N,KODE,M,TOL, EN,NZ,IERR)
